# Original design and acceptance notes

`spec.md` and `eval-rubric.md` preserve the original project brief and development
acceptance rubric, previously stored under `gan-harness/`. They explain the
business constraints behind the implementation; they are not an executable
evaluation harness, a measured score, or a production benchmark.

The project has since evolved into the persisted inquiry → quotation → follow-up
workspace described in the root README. Use that README and the current tests
for supported behavior and validation. For example, Lead Quality is now separate
from Data Completeness, and the dashboard reports observed synthetic-workspace
metrics rather than claiming projected sales impact. The original notes are
retained unchanged for design history.
